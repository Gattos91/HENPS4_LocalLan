# HENPS4_LocalLan
Activar HEN en tu ps4 mediante un archivo tu red Local sin salir a internet 
----------------------------------------------------------------------------
Configurar un servidor HTTP local en Windows 11 para servir los archivos del proyecto PS4 WebKit JB a una PS4 Slim con firmware 11.00-13.00, sin depender de un alojamiento web externo ni disco Blueray con Hen.
